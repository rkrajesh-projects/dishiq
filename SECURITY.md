# Security Policy

## Supported Versions

DishIQ is primarily a demonstration/portfolio project. We currently provide security updates only for the latest main branch.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not disclose it publicly. 

Instead, report it by opening an issue on the repository or by contacting the maintainer at `security@dishiq.example.com` (placeholder). We will review all reports and respond as quickly as possible.
